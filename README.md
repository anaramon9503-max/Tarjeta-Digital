# Tarjeta Digital Nutrioot

Machote de tarjeta de presentación digital para publicar en GitHub Pages.

## Archivos

- `index.html` — contenido y enlaces.
- `style.css` — diseño, colores y adaptación a celular.
- `script.js` — comportamiento de las secciones desplegables.
- `logo.png` — agrega aquí el logo real de Nutrioot.

## Antes de publicar

Busca dentro de `index.html` y reemplaza:

- `5210000000000` por el número real de WhatsApp con lada y sin espacios.
- Los `href="#"` por el enlace real de Agenda Pro, ubicación, Instagram y Facebook.
- Los textos, precios y servicios que quieras actualizar.

## Subir a GitHub Pages

1. Crea un repositorio nuevo en GitHub.
2. Sube `index.html`, `style.css`, `script.js` y `logo.png`.
3. En el repositorio entra a **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Elige la rama `main` y la carpeta `/root`.
6. Guarda los cambios.
7. GitHub te mostrará la URL pública de la tarjeta.

El diseño está pensado principalmente para celular y solo permite una sección de servicios abierta a la vez.
